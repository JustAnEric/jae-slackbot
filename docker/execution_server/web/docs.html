Jae Execution Server

Jae execution server relies primarily on Docker. It allows for Jae to run commands via her toolset.

If you're seeing this page in the browser, it means you probably have already got Docker Compose running, which is great! In here, we'll describe how the protocol works for execution.

How tools communicate

In order to understand this next part, you'll need to understand the premise of WebSockets. The WebSocket protocol allow for persistent, bidirectional communication in ways long-polling or normal HTTP requests don't allow. This server uses the WebSocket protocol at the path /ws and allows for several operations.

If you have further questions about WebSockets, it might be best to check out this article.
